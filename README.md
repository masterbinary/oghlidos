# نصب VS Code و افزونه Live Server

### روش 2: استفاده از Python

```bash
# Python 3
python -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000
```

سپس در مرورگر باز کنید: `http://localhost:8000`

### روش 3: استفاده از Node.js

```bash
# نصب http-server به صورت global
npm install -g http-server

# یا استفاده مستقیم با npx
npx http-server -p 8000
```

### روش 4: استفاده از PHP

```bash
php -S localhost:8000
```

> **⚠️ توجه مهم**: اجرای مستقیم فایل (دابل کلیک) به دلیل محدودیت‌های CORS و سیاست‌های امنیتی مرورگر **کار نمی‌کند**. حتماً از یکی از روش‌های سرور محلی بالا استفاده کنید.

## 🧠 الگوریتم‌های پیاده‌سازی شده

### 1. نزدیک‌ترین همسایه (Nearest Neighbor)

```javascript
// مراحل اجرا:
1. شروع از نقطه شماره 1
2. در هر مرحله، نزدیک‌ترین نقطه بازدید نشده را پیدا کن
3. نقطه را به مسیر اضافه کن
4. تکرار تا همه نقاط پوشش داده شوند
5. بازگشت به نقطه شروع

// ویژگی‌ها:
- پیچیدگی زمانی: O(n²)
- حافظه مصرفی: O(n)
- مزایا: سرعت بالا، سادگی پیاده‌سازی
- معایب: لزوماً بهینه نیست
```

### 2. الگوریتم 2-OPT

```javascript
// مراحل اجرا:
1. دریافت یک مسیر اولیه (معمولاً از Nearest Neighbor)
2. برای هر جفت یال (i,j) که با هم تلاقی دارند:
   - مسیر را در بخش بین i و j معکوس کن
   - اگر طول مسیر کاهش یافت، تغییر را بپذیر
3. تکرار تا هیچ بهبودی ممکن نباشد

// ویژگی‌ها:
- پیچیدگی زمانی: O(n²) تا O(n³)
- مزایا: بهبود موثر مسیرهای اولیه
- کاربرد: بهینه‌سازی محلی مسیر
```

### 3. الگوریتم ژنتیک (Genetic Algorithm)

```javascript
// پارامترهای الگوریتم:
- جمعیت اولیه: 70 کروموزوم (حداقل 20)
- نسل‌های تکامل: 150 نسل (حداقل بر اساس تعداد نقاط)
- نرخ جهش: 8%
- روش انتخاب: تورنومنت (k=3)
- روش ترکیب: Order Crossover (OX)
- روش جهش: Swap Mutation
- حفظ نخبه: یک کروموزوم برتر در هر نسل

// مراحل اجرا:
1. تولید جمعیت اولیه تصادفی
2. محاسبه Fitness برای هر کروموزوم
3. انتخاب والدین با روش تورنومنت
4. تولید فرزندان با ترکیب Order Crossover
5. اعمال جهش با نرخ 8%
6. حفظ کروموزوم برتر (Elite)
7. تکرار مراحل 2-6 تا پایان نسل‌ها
```

### 4. الگوریتم هیبرید (Hybrid: NN + 2OPT)

```javascript
// مراحل اجرا:
1. اجرای الگوریتم Nearest Neighbor
2. دریافت مسیر اولیه
3. اعمال الگوریتم 2-OPT برای بهبود مسیر
4. بازگشت مسیر نهایی

// مزایا:
- ترکیب سرعت NN با کیفیت 2-OPT
- بهترین گزینه برای استفاده عمومی
```

## 📱 طراحی ریسپانسیو

### نقطه شکست (Breakpoints)

```css
/* دسکتاپ بزرگ */
@media (min-width: 1200px) { ... }

/* دسکتاپ معمولی */
@media (max-width: 1200px) and (min-width: 901px) { ... }

/* تبلت */
@media (max-width: 900px) { ... }

/* تبلت کوچک */
@media (max-width: 768px) { ... }

/* موبایل */
@media (max-width: 480px) { ... }
```

### تغییرات در هر اندازه

| اندازه صفحه | منوی بالا | منوی همبرگری | پنل کناری | سایز فونت | step-dot |
|-------------|-----------|-------------|-----------|-----------|----------|
| > 900px | ✅ نمایش کامل | ❌ مخفی | 380px | نرمال | 36px |
| 480px - 900px | ❌ مخفی | ✅ نمایش | 320px | کوچک | 32px |
| < 480px | ❌ مخفی | ✅ نمایش | 280px | خیلی کوچک | 28px |

### تغییرات پنل کناری در موبایل

| حالت | عرض | موقعیت |
|------|-----|--------|
| باز | 280px | right: 10px |
